# E-commerce module (frontend stub)

This folder is the frontend half of the optional e-commerce module. It is a self-contained feature stub that `php artisan kit:install` copies verbatim into `apps/web/src/features/ecommerce/` **only** when the E-commerce preset is selected — a Basic build carries no e-commerce code and never mounts it (the app router globs `@/features/*/routes.ts`, which the stub location is deliberately outside of). Because it is relocated at install time, everything here uses either package imports (`@app/types`) or the location-independent `@/` alias, and internal cross-references between sub-features use RELATIVE paths, so the folder works identically in `stubs/` and in `src/features/ecommerce/`. `types.ts` holds the shared API contract (mirrors the backend `*Resource` classes exactly: UUID ids, `IsoDateTime` timestamps, money in integer minor units) and `routes.ts` aggregates each sub-feature's `./<sub>/routes.ts` into one `AppRouteRecord[]`. The stub still type-checks and unit-tests in place (via `apps/web/tsconfig.json` and `vitest.config.ts` includes) but is never bundled into the SPA until installed.
